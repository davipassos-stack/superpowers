# Modelo: omakase / sushi bar

Página única, escura (índigo, creme e vermelhão), com abertura de tela cheia, experiência, galeria, reserva pelo
WhatsApp, visita com horários e rodapé. HTML, CSS e JS puros, sem build.

- Dados do restaurante (nome, bairro, rua, WhatsApp, Instagram): `site.js`
- Textos: `index.html`
- Cores e fontes: topo do `style.css`
- Fotos: `img/` (as atuais são de exemplo, do Wikimedia Commons; troque pelas do cliente e atualize os créditos no rodapé)

Acessibilidade: link "Pular para o conteúdo", foco visível, rótulos em todos os campos, erros escritos embaixo de cada
campo, textos com contraste alto e animações desligadas para quem prefere menos movimento.
